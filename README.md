# ЧУЖАЯ ПАРТА — AI-сериал

Первый эпизод собран на Remotion. В проект добавлен AI-медиапайплайн: Fish Audio создаёт русскую озвучку рассказчика, а fal.ai / FLUX генерирует кинематографичные фоны 10 сцен. Персонажи и титры остаются отдельными анимированными слоями Remotion, чтобы сохранять движение и читаемый текст. Для работы генерации нужны собственные API-ключи; без них сохраняется SVG-режим предпросмотра.

## Требования

- Node.js 20+
- npm

## Подключение AI-медиа

1. Скопируй `.env.example` в `.env` и заполни `FISH_API_KEY` и `FAL_KEY`.
2. При желании укажи `FISH_REFERENCE_ID`, если в Fish Audio уже выбран подходящий голос.
3. Установи зависимости и запусти генерацию:

```bash
npm install
npm run generate:assets
```

4. Собери эпизод с озвучкой и AI-фонами:

```bash
npm run render:ai
```

Скрипт сохраняет 10 аудиофрагментов в `public/assets/audio/` и 10 фонов в `public/assets/scenes/`. Ключи API не нужно добавлять в исходники или коммитить в GitHub. Для автоматической сборки добавь `FISH_API_KEY` и `FAL_KEY` в GitHub repository secrets; `FISH_REFERENCE_ID` необязателен. Если ключей нет, CI собирает безопасный SVG fallback без AI-медиа.

## Запуск предпросмотра

```bash
npm install
npm run dev
```

## Проверка TypeScript

```bash
npm run typecheck
```

## Рендер MP4 локально

```bash
npm run render
```

Для CI используется более оптимизированный рендер:

```bash
npm run render:ci
```

Готовый файл: `out/episode-01.mp4`.

## Автоматическая сборка на GitHub

Workflow **Build episode 01** запускается при каждом push в `main` и вручную через GitHub Actions. Он устанавливает зависимости, проверяет TypeScript, подготавливает браузер Remotion, рендерит весь эпизод и публикует MP4 как артефакт сборки на 14 дней.

## Параметры эпизода

- 1920×1080
- 30 FPS
- 9 900 кадров
- 5 минут 30 секунд
- 10 сцен + opening и closing
