# ЧУЖАЯ ПАРТА — AI-сериал

Первый эпизод создаётся на Remotion: полностью анимированная 2D-иллюстрация, без актёров и без озвучки на этом этапе.

## Запуск

```bash
npm install
npm run dev
```

## Рендер эпизода

```bash
npm run render
```

Видео: 1920×1080, 30 FPS. Озвучка рассказчика пока намеренно не добавлена — история передаётся визуальными сценами и экранными репликами.
