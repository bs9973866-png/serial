# ЧУЖАЯ ПАРТА — AI-сериал

Первый эпизод собран на Remotion. Русская озвучка по умолчанию создаётся бесплатным Edge TTS голосом ru-RU-DmitryNeural — API-ключ не нужен. Если настроен FISH_API_KEY, можно вместо него использовать Fish Audio. Кинематографичные фоны через fal.ai / FLUX — дополнительная опция, требующая FAL_KEY. Персонажи и титры остаются отдельными анимированными слоями Remotion.

## Требования

- Node.js 20+
- npm

## Подключение AI-медиа

1. Установи Python и Edge TTS: `python -m pip install edge-tts`.
2. Для бесплатной озвучки больше ничего настраивать не нужно. Голос по умолчанию — `ru-RU-DmitryNeural`; можно заменить его через `EDGE_TTS_VOICE`.
3. При желании добавь `FAL_KEY` для AI-фонов или `FISH_API_KEY` для альтернативной озвучки Fish Audio.
4. Запусти генерацию:

```bash
npm install
npm run generate:assets
```

4. Собери эпизод с озвучкой и AI-фонами:

```bash
npm run render:ai
```

Скрипт сохраняет 10 аудиофрагментов в `public/assets/audio/` и 10 фонов в `public/assets/scenes/`. Ключи API не нужно добавлять в исходники или коммитить в GitHub. Для автоматической сборки достаточно встроенного Edge TTS: GitHub Actions сам устанавливает пакет и создаёт русскую озвучку без ключей. `FAL_KEY` нужен только для генерации AI-фонов, а `FISH_API_KEY` и `FISH_REFERENCE_ID` — если хочешь использовать Fish Audio вместо Edge TTS.

## Запуск предпросмотра

```bash
npm install
npm run dev
```

## Проверка TypeScript

```bash
npm run typecheck
```

## Рендер MP4 локально

```bash
npm run render
```

Для CI используется более оптимизированный рендер:

```bash
npm run render:ci
```

Готовый файл: `out/episode-01.mp4`.

## Автоматическая сборка на GitHub

Workflow **Build episode 01** запускается при каждом push в `main` и вручную через GitHub Actions. Он устанавливает зависимости, проверяет TypeScript, подготавливает браузер Remotion, рендерит весь эпизод и публикует MP4 как артефакт сборки на 14 дней.
